💡 Should you run any SQL schema in Neon?

No manual schema execution is needed! OmniPOS auto-detects and creates all tables (tenants, products, sales, stock_logs, transfers) with initial seeds automatically when connected to your Neon database URL.

Connecting your Neon database:

  1. Create a free database at neon.tech
  2. Copy your connection string: postgres://user:pass@ep-xyz.region.aws.neon.tech/neondb?sslmode=require
  3. Set the DATABASE_URL environment variable in your deployment or container settings.
